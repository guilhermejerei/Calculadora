## ✨ Funcionalidades

- ✅ Operações básicas: adição, subtração, multiplicação e divisão
- ✅ Cálculo de porcentagem
- ✅ Suporte a números decimais
- ✅ Apagar último caractere (DEL)
- ✅ Limpar tudo (AC)
- ✅ Feedback sonoro nos botões (sons de toque e resultado)
- ✅ Atalho de teclado: tecla **Enter** para calcular
- ✅ Tratamento de erros (divisão por zero, expressão inválida)
- ✅ Resultado em notação científica para números muito grandes
- ✅ Respeita precedência de operadores (multiplicação e divisão antes de adição e subtração)
- ✅ Acessível: `aria-labels` em todos os controles interativos

## 🚀 Como usar

### Rodar localmente

1. Clone o repositório ou baixe o ZIP:
   ```bash
   git clone https://github.com/guilhermejerei/Calculator-JS-main.git
   ```
2. Abra o arquivo `index.html` diretamente no navegador — não é necessário servidor.

### Usar a calculadora

| Ação | Como fazer |
|------|------------|
| Inserir número | Clique no botão do número desejado |
| Operação | Clique no operador (`+`, `-`, `x`, `/`, `%`) |
| Calcular | Clique em `=` ou pressione **Enter** |
| Apagar um caractere | Clique em **DEL** |
| Limpar tudo | Clique em **AC** |
